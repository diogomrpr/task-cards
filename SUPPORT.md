# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Include the Task Cards version, VS Code version, workspace type, reproduction steps, and a sanitized task definition.

Before filing an issue:

- Confirm the task is explicitly declared in a workspace-folder `.vscode/tasks.json` file.
- Reload the Task Cards view and check `tasks.json` for errors.
- Remember that Task Cards confirmation applies only to launches initiated from a card.
- Remove commands, paths, arguments, and screenshots that contain secrets.

Security reports must follow [SECURITY.md](SECURITY.md).
